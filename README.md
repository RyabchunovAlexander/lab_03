# Медиатека - каталог объектов

Лабораторная работа №3 по предмету "Программирование на Python". Пакет для управления каталогом медиафайлов.

## Что делает программа

- **Управление сущностями** — позволяет создавать объекты медиатеки (фильмы, музыка, книги) с валидацией полей (ID, название, категория, год, автор, длительность).
- **Быстрый поиск** — работает через словарные индексы, что позволяет находить объекты по ID и категории моментально, без перебора всей коллекции.
- **Защита от ошибок** — запрещает дубликаты ID и возвращает понятные предметные исключения при попытке найти или удалить несуществующий элемент.
- **Сохранение данных** — выгружает и загружает каталог в JSON с проверкой версии формата и защитой от поврежденных файлов (атомарность).

## Установка и подготовка

```bash
# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate

# Установка пакета и зависимостей для тестов
pip install pytest ruff
pip install -e .
```

## Использование

```bash
# Запуск демонстрации (создание, поиск, сохранение, загрузка)
python -m catalog

# Запуск автоматических тестов (26 штук: модели, каталог, сохранение)
python -m pytest

# Проверка качества кода и стиля
python -m ruff check .
```

## Технологии

- Python 3.10+
- Встроенный модуль json (с ensure_ascii=False для кириллицы)
- dataclasses (автоматическая генерация __init__)
- **pytest** (автоматическое тестирование независимых тест-кейсов)
- **ruff** (линтинг кода)
